# 🧭 Fiche de cadrage d'un cas d'usage IA

*À remplir avec le métier lors d'un entretien de 30 minutes, avant de concevoir un skill.*

## 1. Le besoin
- **Qui ?** Équipe, métier, nombre d'utilisateurs potentiels :
- **Quelle tâche ?** Décrivez-la comme à un nouvel arrivant :
- **Fréquence et durée actuelles :** … fois par semaine, … minutes à chaque fois
- **Qu'est-ce qui est pénible aujourd'hui ?**

## 2. Les données
- **Entrée :** que fournit l'utilisateur ? (texte, fichier, tableau…)
- **Sensibilité :** données personnelles ? secret bancaire ? confidentiel ? → ☐ Non ☐ Oui, lesquelles :
- **Exemple réel disponible ?** ☐ Oui (anonymisé) ☐ Non

## 3. Le résultat attendu
- **Sortie :** quel format ? (e-mail, tableau, synthèse…)
- **À qui est-il destiné ?** ☐ Interne ☐ Client / externe
- **À quoi ressemble un « bon » résultat ?**

## 4. Évaluation rapide

| Critère | Note (1–5) |
|---|---|
| Volume / fréquence | |
| Gain de temps par utilisation | |
| Faisabilité avec l'IA générative (tâche de texte, règles claires) | |
| Faible risque (données, impact d'une erreur) | |
| **Total /20** | |

> **≥ 14** : candidat prioritaire · **10–13** : à approfondir · **< 10** : à écarter ou à repenser
